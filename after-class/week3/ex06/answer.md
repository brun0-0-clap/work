# ex06 StackOverflow 高质量与低质量问题对比

## 高赞优质问题
问题简述：Python调用subprocess，shell=True时环境变量无法生效
核心要素：
1. 写明运行环境：Python版本、操作系统。
2. 贴出完整最小复现代码。
3. 给出完整报错堆栈信息。
4. 说明自己已经尝试过的排查手段，以及得到的现象。
5. 清晰说明预期行为和实际发生的行为。

为什么容易得到回答：
提问者把复现条件全部给出，回答者不需要反复追问细节，可以直接复现问题进行分析，节约双方时间。

## 被关闭的低质量问题
问题简述：“我的Python代码不运行，帮我看看哪里错了”
核心要素：
1. 没有贴代码，或者只贴残缺片段。
2. 没有报错信息，只描述“程序不工作”。
3. 没有说明系统版本、Python版本。
4. 没有写自己已经做过哪些尝试。

为什么很难得到有效答案：
信息严重缺失，回答者无法复现故障，需要大量来回追问才能拿到基础信息，社区会倾向关闭这类问题。

## 总结：写出好技术提问的要点
1. 写明软件版本、操作系统环境。
2. 提供最小可复现代码，不要贴一大段无关业务代码。
3. 完整复制报错信息，不要只转述报错。
4. 写清楚：你想要什么结果，实际得到什么结果。
5. 列出自己已经尝试过的解决操作。
